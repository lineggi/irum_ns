계단 실측 디지털화

계단 실측표 사진을 올리면 손글씨 치수를 인식해 표로 정리하고, 검토·수정 후 엑셀(계단별 시트 + 치수별 개수 집계)로 내려받습니다.

필기가 흐리거나 오독이 잦으면 Pro로 바꿔 다시 인식하세요.
API 키는 서버(Vercel 환경변수)에 안전하게 보관되어 있어 별도 입력이 필요 없습니다. 인식 요청은 이룸NS 서버를 거쳐 Google Gemini로 전송됩니다.
사진은 손글씨 인식을 요청할 때만 이룸NS 서버를 거쳐 Google Gemini로 전송됩니다. 표 데이터는 이 브라우저 밖으로 저장되지 않습니다.
